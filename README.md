# 中鋼德英出差互動行程網站（第一版）

## 如何使用
1. 解壓縮 ZIP。
2. 雙擊 `index.html`，使用 Chrome 或 Edge 開啟。無須安裝程式或連網。
3. 可切換日期、查看航班／客戶／飯店，個人筆記儲存在本機瀏覽器，無法跨裝置同步。
4. `trip-data.json` 是供後續修改的資料副本；第一版網站的資料已內嵌在 `index.html`，**單獨修改 JSON 不會自動更新網頁**。更新資料需同步重建 index.html。

## GitHub 安全發布指引
- 請先向公司資訊安全管理單位確認是否允許將出差與客戶資料存放在 GitHub。
- 若核准，建立 **Private** Repository，僅邀請經授權的同仁（Settings → Collaborators）。啟用 GitHub 帳號 2FA，並依最小權限管理。
- **不要開啟一般 GitHub Pages**：Private Repository 不代表 Pages 會要求登入；一般公開 Pages 網址可能讓未授權人士存取內容。
- 需要網頁連結供內部同仁觀看時，應部署在公司既有的內部網站／VPN／SSO 驗證平台，並由 IT 配置身分驗證、存取權限及稽核。只有在組織方案明確提供並驗證 Pages 私有存取控制時，才可考慮相應方案。
- 靜態網頁的前端密碼鎖、隱藏網址、robots.txt、或 GitHub 私人 Repo 都**不是**網站存取保護。
- 不要上傳原始機票 PDF、訂位代號、會員卡號、護照資料、機密價格、客戶個資及未經核准的商業資訊。
- 此版本不包含登入功能，適合離線審閱或部署到有驗證的內部平台。
