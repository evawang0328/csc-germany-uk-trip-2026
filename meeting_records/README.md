# 客戶會議紀錄索引 | Meeting Records

本資料夾規劃供德國／英國 2026 年客戶拜訪會議紀錄使用。

## 命名規範
- `YYYY-MM-DD_Customer_Meeting_Record.pdf` — 手機閱讀版本
- `YYYY-MM-DD_Customer_Meeting_Record.docx` — 可編輯的 Word 原稿

例如：`2026-11-11_Duferco_Dinner_Meeting_Record.pdf`

## 網站呈現方式（待實作）
- 「06 客戶資料」：前次拜訪資料 / 網路彙整 / 本次會議紀錄
- 本次會議：日期、重點摘要、追蹤事項、PDF 閱讀及 Word 下載
- 「09 客戶訪談問題」：可連結至已完成的會議紀錄

## 文件發布注意事項
此 Repository 為 Public。GitHub Pages 網頁上的 HTML / JavaScript 密碼，**不能限制直接存取此 Repository 的 PDF、DOCX、JSON 等檔案**。
如文件含客戶報價、訂單、個資或公司內部資訊，請勿直接上傳此公開資料夾；請先取得公司核准或改用具真正存取權限的公司文件平台，並僅在網站連結至授權來源。
